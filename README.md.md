## 🇧🇷 Português

### 📋 Descrição
Jogo interativo de adivinhação de números desenvolvido em Python.
O jogador tenta descobrir um número secreto gerado aleatoriamente,
recebendo dicas a cada tentativa. Possui 3 níveis de dificuldade,
sistema de pontuação e placar acumulado entre rodadas.

### 🚀 Como executar
**Pré-requisitos:** Python 3.8 ou superior instalado.

```bash
# Clone o repositório
git clone https://github.com/MarcoCostaSilva/jogo-adivinhacao.git

# Acesse a pasta
cd jogo-adivinhacao

# Execute o programa
python programa1_jogo_adivinhacao.py
```

### 🎮 Como jogar
1. Escolha o nível de dificuldade: Fácil, Médio ou Difícil
2. Digite seus palpites numéricos quando solicitado
3. Receba dicas: o número secreto é maior ou menor?
4. Tente acertar antes de esgotar as tentativas
5. Veja seu desempenho e escolha jogar novamente

### 🧠 Níveis de dificuldade
| Nível | Intervalo | Tentativas |
|-------|-----------|------------|
| Fácil | 1 a 50 | 10 |
| Médio | 1 a 100 | 7 |
| Difícil | 1 a 200 | 5 |

### 📚 Conceitos aplicados
- **Estruturas de decisão simples e compostas** — verificação do palpite com `if/else`
- **Estruturas de decisão aninhadas e múltipla escolha** — seleção de dificuldade e classificação de desempenho com `if/elif/else`
- **Repetição com variável de controle** — controle de tentativas com `for`
- **Repetição com teste no início** — loop principal do jogo com `while`

## 🇺🇸 English

### 📋 Description
An interactive number guessing game developed in Python.
The player tries to discover a randomly generated secret number,
receiving hints after each attempt. Features 3 difficulty levels,
a performance rating system and cumulative score between rounds.

### 🚀 How to run
**Prerequisites:** Python 3.8 or higher installed.

```bash
# Clone the repository
git clone https://github.com/MarcoCostaSilva/jogo-adivinhacao.git

# Navigate to the folder
cd jogo-adivinhacao

# Run the program
python programa1_jogo_adivinhacao.py
```

### 🎮 How to play
1. Choose a difficulty level: Easy, Medium or Hard
2. Enter your numeric guesses when prompted
3. Receive hints: is the secret number higher or lower?
4. Try to guess before running out of attempts
5. Check your performance and choose to play again

### 🧠 Difficulty levels
| Level | Range | Attempts |
|-------|-------|----------|
| Easy | 1 to 50 | 10 |
| Medium | 1 to 100 | 7 |
| Hard | 1 to 200 | 5 |

### 📚 Concepts applied
- **Simple and compound decision structures** — guess checking with `if/else`
- **Nested and multiple-choice decisions** — difficulty selection and performance rating with `if/elif/else`
- **Loop with control variable** — attempt counter with `for`
- **Loop with test at the beginning** — main game loop with `while`
